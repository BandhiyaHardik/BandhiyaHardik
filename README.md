## 🐙 Open Source

Open source played a big role in my journey from **learner → contributor → organizer → mentor → community leader**.

Through FOSST, GSSoC, Hacktoberfest and other open-source communities, I enjoy helping beginners understand:

- how Git and GitHub actually work
- how to find beginner-friendly issues
- how to make their first contribution
- how to communicate with maintainers
- how to move beyond "just making a PR" and understand the project

For me, open source is as much about **people and collaboration** as it is about code.
